# Wedding Invitation Website

## Structure

The wedding invitation website is organized into the following main folders and files:

- `/assets` - This directory contains all the static assets like images and stylesheets.
  - **Images**: Store all images in this folder.
  - **Stylesheets**: Store CSS files for styling in this folder.

- `/src` - This is the source code directory where all the HTML and JavaScript files are.
  - **index.html**: The main HTML file that serves as the entry point of the website. Edit to update the homepage content.
  - **about.html**: This file contains information about the couple and wedding details. Update this file for any changes regarding the couple.
  - **RSVP.html**: The RSVP page. Edit this file to change RSVP instructions or details.

## Instructions for Editing

1. **Access the Files**: Use a code editor or GitHub interface to access and edit the files in the repository.
2. **Make Changes**: Navigate to the appropriate file to make any necessary changes. 
3. **Commit Changes**: Once you make changes, commit them with a descriptive message about what was altered.
4. **Push Changes**: Push your changes to the repository to update the live site.

## Tips
- Always back up files before making significant changes.
- Test HTML changes locally before pushing them to ensure everything works correctly.
- Ensure images used are optimized for web use to improve loading times.
